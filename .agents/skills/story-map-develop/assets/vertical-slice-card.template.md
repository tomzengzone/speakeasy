# Child Vertical Slice 输出模板

用于在现有 User Story 的 `Child Vertical Slices:` 表中输出 Child Vertical Slice。

```md
Child Vertical Slices:

| Id | description | Status |
| --- | --- | --- |
| `VS-0042-1` | <说明触发或入口、业务对象、用户选择或业务决策、状态影响和可见结果。> | `draft` |
```

父子关系由所在 User Story 的嵌套位置表达；模板不增加 Capability、Parent 或下游 Artifact 列。
