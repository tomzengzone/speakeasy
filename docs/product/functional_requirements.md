# 功能需求目录

本文件只保留 [测试用例目录](../quality/test_cases.md) 中 FR-TC 直接引用的产品行为。

| ID | Status | source_vs_ids | Requirement |
| --- | --- | --- | --- |
| `FR-TRAIN-001` | `approved` | `VS-TRAIN-001-1` | 学习者完成当前官方场景的一轮语音练习并触发结束动作后，系统必须展示本轮练习总结和可见的后续学习入口；练习结果失败或不可用时，系统必须展示可恢复的错误或空状态，不得错误推进学习进度。 |
| `FR-CONTENT-001` | `approved` | `VS-CONTENT-001-1` | 内容资产入口中“全部”场景主题集合必须恰好包含全部已发布且对当前学习者可见的官方场景主题；选中主题后的课程摘要集合必须恰好包含该主题下全部已发布且对当前学习者可见的课程。每条课程摘要必须包含非空英文标题、非空中文简介与唯一一个 A1/A2/B1/B2/C1/C2 等级。已发布且可见的主题即使没有可见课程也必须保留并显示真实空状态；获取失败不得伪装为空状态。L1/L2/L3 和其他别名均必须被拒绝。 |
| `FR-CONTENT-002` | `approved` | `VS-CONTENT-002-1` | 一门已发布课程必须具有非空英文标题、非空中文简介、唯一一个合法 CEFR 等级，以及大于零且携带单位的典型完成时长；从不同入口打开同一课程时，必须解析并展示同一已发布课程及同一版本。背景图可缺省；课程或版本无法精确解析时不得使用其他课程、其他版本或占位值替代。 |
| `FR-ACC-001` | `approved` | `VS-ACC-009-1` | 只有无法正常登录、主动选择账号恢复，并通过账号已绑定且仍可使用的手机号完成有效的一次性验证码身份验证的学习者，才符合恢复资格；验证成功时，系统必须将该手机号已绑定的既有账号确认为唯一恢复目标，已消费验证码不得再次用于恢复。 |
| `FR-ACC-002` | `approved` | `VS-ACC-009-1` | 账号恢复成功后，系统必须保留经验证确认的原账号、学习数据和订阅权益状态，撤销该账号的全部既有会话，并且不得因恢复成功直接建立新会话；学习者必须使用已验证且仍可用的手机号重新登录后才能恢复访问。 |
| `FR-ACC-003` | `approved` | `VS-ACC-009-1` | 账号不存在、手机号未绑定或不可用、验证码发送失败、验证失败、验证码过期，或恢复流程在成功前中断时，本次恢复必须整体失败；系统不得创建新账号、改变身份凭据或改变任何会话，并必须允许学习者重新尝试账号恢复。 |
