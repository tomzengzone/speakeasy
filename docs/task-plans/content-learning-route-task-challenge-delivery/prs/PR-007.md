# PR-007: Backend 学习路线投影

## Objective

以 TDD 实现 additive Course launch references 和 Learning-owned route projection/GET endpoint；只读取现有 Course binding 与
Practice session 状态，固定返回五阶段，不新增 stage table 或第二套 progress store。

## Included Scope

- 新增 `V202608110001__course_practice_launch_context.sql`：PracticeSession 三个 nullable Course refs、all-null/all-non-null check、FK 与查询索引。
- 在现有 PracticeSession entity/repository 中映射 references，并提供按 user + CourseVersion + binding 查询状态所需最小 selector。
- 新建 Learning route projection，精确解析 published/visible Course/version/binding，并由现有 CourseController 暴露 GET route。
- stage 01 按 completed > active/feedback/recoverable > none 映射；读取依赖失败映射 unknown；02–05 固定真实未交付。
- 增加三个定向测试；测试 fixture 可以写 Course/session 数据，production migration 不写内容 DML。

## Excluded Scope

- Practice session course launch/start、AI opener、audio playback、Flutter、stage table 或生产 seed。
- 改写既有 migration、回填 legacy session、把 progress 持久化到 Content。

## Acceptance Criteria

- migration 仅 additive DDL，三 refs 全空/全非空，FK 指向现有 Course facts，索引支持 exact user/version/binding projection；无 stage 表和 Course DML。
- route endpoint 不静默切换 version/binding；隐藏/未发布/不存在保持既有 privacy-safe Course read semantics。
- stage 01 状态优先级与 failure→unknown 正确；completed/unknown 时 `next_stage_code=null`；从不推荐 02–05。
- legacy null refs 可正常读取，既有 Practice path 不受影响。
