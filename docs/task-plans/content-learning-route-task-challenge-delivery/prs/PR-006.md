# PR-006: 路线与挑战 UX 契约

## Objective

使用已批准产品/API/AI 契约定义课程详情中的五阶段路线和只读任务挑战体验，覆盖独立加载/错误恢复、历史消息、
authenticated audio playback、AI opener、返回路径和可访问性；明确页面不出现录音、composer 或 submit-turn 控件。

## Included Scope

- Course detail 内独立 route loading/success/error/retry，不遮蔽已加载的课程正文。
- 固定 01–05 顺序、状态/不可用原因、next-stage 提示；仅 01 可点击。
- Challenge 页展示精确课程标题/CEFR、role-separated history、AI opener、消息级播放状态和返回课程路线。
- 定义无历史、无音频、404、503、播放中/失败/重试、session load failure 的可恢复 UI。
- 定义稳定 accessibility keys/semantics、focus order、状态文案和 User Flow；增加 UX Contract-TC。

## Excluded Scope

- 视觉品牌重做、录音/发送/转写/多轮回复、Backend/API 变化或页面实现。
- 为 02–05 创建 placeholder content page 或伪造可进入操作。

- `docs/ux/screen_spec.md`

- `docs/ux/usability_checklist.md`

## Context Budget

- 上限：18k tokens。
- 只加载 003/004 VS/FR、route/session/audio API 与 opener failure semantics、现有 CourseDetailPage 和 Practice UI pattern；不设计 US-005 interaction。

## Acceptance Criteria

- route 与 course detail 使用独立状态；route retry 不触发详情重载，也不清除已知标题/版本上下文。
- 02–05 明确“暂未交付”且不可操作；unknown 进度不显示“尚未开始”；next-stage 不指向未交付阶段。
- challenge 的 coach/learner message 在视觉和语义上可区分；无历史只显示 opener，不伪造 learner message。
- 音频按钮只在 `audio_available=true` 显示；404 收敛为不可播放，503 可重试；返回路线始终可用。
- selectors 与 Contract-TC 能稳定定位路线阶段、重试、challenge context、消息 role、播放/失败状态；不存在 recorder/composer/submit selector。

- 可访问性与 copy 是本卡验收内容，不延后到 Flutter 实现临时决定。
