# PR-004: API、OpenAPI 与 generated Dart client

## Objective

把已接受的产品与领域事实固化为 learning-route、Practice course launch/session response 和 authenticated message audio 四项 API 契约，
同步 OpenAPI、examples、generator、generated Dart decoder 与 drift manifest，不手写第二套 DTO。

## Included Scope

- 定义 `GET /courses/{course_id}/versions/{course_version_id}/learning-route` 的五阶段、状态、可用性、原因与 nullable next stage。
- 扩展 `POST /practice/sessions` 为 legacy tuple 与 `course_launch` one-of；两组并存或缺失返回 `422`。
- 扩展 PracticeSession response 的 nullable `course_context`、message `audio_available` 和持久 opener 表达。
- 定义 `GET /practice/sessions/{session_id}/messages/{message_id}/audio` 的 `audio/*`、private/no-store、privacy-safe 404 与 503。
- 更新 API Contract、OpenAPI/examples、Dart generator、generated client、drift manifest、Contract-TC 与 traceability。

## Excluded Scope

- Java controller/service、数据库 migration、Prompt 内容、Flutter 页面或手写 feature-local DTO/client。
- 新 signed URL endpoint、object key/provider URL 暴露或 legacy request 破坏。

## Acceptance Criteria

- OpenAPI one-of 阻止 legacy/course_launch 同时出现；Course launch 不接受客户端 scenario/level 替换 authored binding 事实。
- route enums 与 next-stage null 规则完整；02–05 使用 `STAGE_NOT_DELIVERED`，不得映射成 not_started。
- playback operation 不公开 media storage locator，404/503 和 cache/content-type header 可测试。
- generated Dart 完全由现有 generator 产生，manifest/hash 同步，legacy Practice decode 继续通过。
- Contract-TC 覆盖 route、exact launch、legacy compatibility、playback security、generated drift，并有 traceability。
