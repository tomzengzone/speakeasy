# PR-003: 领域与持久化契约

## Objective

在不改变 Content/Practice/Learning 所有权的前提下，定义 Course-linked PracticeSession 与 opener 的最小领域事实、关系、不变量、
持久化兼容和删除/回滚语义，为 API 与 migration 提供唯一 Domain Contract。

## Included Scope

- 定义 nullable `CourseLaunchReference(course_id, course_version_id, course_content_binding_id)`。
- 定义三引用全空或全非空、legacy session 兼容、exact binding 恢复隔离、每会话最多一个持久化 opener。
- 定义 Learning-owned route projection 如何只读 Course binding 与 Practice session 状态，不把 progress 写入 Content。
- 定义 account deletion、音频引用生命周期、additive migration 和保留 nullable 历史数据的 rollback。
- 增加 Domain Contract-TC 并刷新 traceability。

## Excluded Scope

- API path/payload、OpenAPI、Prompt 文案、Screen Spec、SQL 或 Java/Dart 实现。
- stage entity/table、第二个 message store、legacy session 回填或破坏性 down migration。

## Acceptance Criteria

- ownership 表清楚区分 Content authored binding、Practice session/opener/message、Learning derived route status、Media asset lifecycle。
- Course launch 三引用满足 all-null/all-non-null，legacy 行无需回填；恢复 key 包含 user + version + binding，不退化到 scenario + level。
- opener 唯一性、消息顺序、删除/过期音频与账号删除行为可由 Contract-TC 验证。
- rollback 不删除新增列或历史数据；关闭入口后 legacy session 路径继续可用。
