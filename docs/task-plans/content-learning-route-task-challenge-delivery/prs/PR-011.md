# PR-011: Flutter 任务挑战与回放

## Objective

在 `FE-PRACTICE-RUNTIME` 目标目录增加 Course session bootstrap/restore controller，在现有 `FE-SCENARIO-PRACTICE` 物理目录增加
只读任务挑战页，复用 generated Practice DTO、ApiClient 与 AudioService 展示 exact context、历史消息、opener 和 authenticated playback。

## Included Scope

- 新建 `CoursePracticeSessionController`，提交 course_launch、恢复 session、校验 course_context identity、管理 load/retry/history state。
- 新建 challenge page，显示 course title/CEFR、coach/learner role、历史文本、opener、message audio play/loading/error/retry 与返回路线。
- 由 CourseDetailPage stage 01 intent 打开 challenge，并保留 exact Course/version/binding launch reference。
- 在现有 ApiClient/AudioService 上增加 authenticated byte playback seam；不创建 direct HTTP/provider/audio implementation。
- 增加 controller、widget、audio playback 三个测试和精确静态分析；补充必要本地化字符串/生成文件。

## Excluded Scope

- recorder、composer、submit-turn、ASR、new learner message、多轮 AI reply、评分/反馈、第二 runtime 或 Backend/DB 测试。
- 把新代码放入 deprecated `FE-SCENARIO-INTERVIEW` 语义；物理目录复用不改变稳定 SWC allocation。

## Context Budget

- 上限：18k tokens。
- 只加载 generated Practice/audio contracts、existing ApiClient/AudioService、Course detail handoff、Practice Runtime seam 与三个目标测试；不加载录音/turn submission loop。

## Acceptance Criteria

- controller 只发 course_launch，不推导 scenario/level；response context 必须匹配 launch identities，不匹配时进入可恢复错误且不展示错误课程。
- challenge 显示 exact title/CEFR、按 role 区分的历史、单一 opener；无历史或无音频有真实空/不可用状态。
- playback 经 authenticated session/message endpoint 与现有 AudioService；404 变为不可播放，503/transport failure 可重试，切页/销毁时停止并释放。
- 返回 route 始终可用；页面树、controller 与 tests 中不存在 recorder、composer、submit-turn 或新消息发送路径。
- 未创建第二 ApiClient、AudioService、message store 或 practice runtime。
