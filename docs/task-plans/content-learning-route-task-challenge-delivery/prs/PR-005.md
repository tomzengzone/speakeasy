# PR-005: AI 开场契约与 eval

## Objective

使用现有 AI Gateway 约束定义一次性 Practice opener 的 prompt、结构化输出、fallback、状态机和脱敏观测，
并把 A1/C1 适配与 provider/schema failure 固化到现有 AI eval runner。

## Included Scope

- 定义 `PracticeOpeningCandidate`：`schema_version=1`、非空英文 `opening_text`、最多 240 字符。
- 明确禁止 correction、score、mastery、next-action 字段，以及课程/用户敏感内容的非必要暴露。
- 定义状态机：new course session 请求一次、成功或 fallback 后持久化、resume 不再调用 provider。
- 定义 deterministic fallback：`Let’s practice {course_title}. What would you like to say first?`，失败不阻断 session。
- 扩展现有 eval runner/fixtures，覆盖 A1、C1、invalid JSON、timeout、超长/空文本和禁止字段。
- 增加 AI Contract-TC 与 traceability。

## Excluded Scope

- AI provider 新选型、新 endpoint、Java gateway implementation、Practice migration 或 Flutter UI。
- 多轮回复、纠错、评分、掌握度、推荐下一动作或 US-CONTENT-005 行为。

## Acceptance Criteria

- prompt 只接收已验证的 course title/CEFR/topic context，输出候选严格满足 schema 与 240 字符边界。
- validator 拒绝 unknown/forbidden fields、invalid JSON、空或非英文 opening；所有拒绝路径使用同一 deterministic fallback。
- eval 至少包含 A1/C1 合法样例与 invalid JSON、timeout、禁止字段样例，并证明 fallback 不阻断 session。
- telemetry 只记录 schema/fallback/provider outcome 与稳定 request/session reference，不记录完整 prompt、opener 或用户历史消息。
