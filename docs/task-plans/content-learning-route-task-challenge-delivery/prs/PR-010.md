# PR-010: Flutter 课程学习路线

## Objective

扩展现有 `CourseCatalogApi` adapter 消费 generated learning-route DTO，在 `CourseDetailPage` 内独立加载/重试路线并渲染五阶段、
真实状态/不可用原因与下一动作；复用现有 Course detail rollback flag，不增加 Course store/client/version resolver。

## Included Scope

- 在现有 CourseCatalogApi/ApiClient adapter 增加 exact course/version route 调用，直接解码 generated DTO。
- CourseDetailPage 保留详情正文，增加独立 route loading/success/error/retry state。
- 渲染固定五阶段顺序、progress/availability/reason 与 next action；仅 available stage 01 产生进入 intent。
- 复用 `AppConfig.enableContentCourseDetail` 控制 route/challenge 入口；flag off 时保持当前详情行为。
- 增加 API adapter test、widget test 和精确文件静态分析；补充必要本地化字符串/生成文件。

## Excluded Scope

- Challenge page/session controller/audio playback、Backend/DB/AI test、新 store/cache/client、silent latest-version resolver。
- 02–05 导航或 placeholder page。

- 上限：16k tokens。
- 只加载 generated route DTO、CourseCatalogApi/ApiClient、CourseDetailPage、现有 content widget test patterns 与路线 UX selectors；不加载 Practice/Audio 实现。

## Acceptance Criteria

- 请求始终使用当前详情的 exact course_id + course_version_id；identity mismatch 被拒绝且不替换页面上下文。
- route failure/retry 不清除课程正文；retry 只重发 route request。
- 02–05 显示 unknown/unavailable/未交付，不显示未开始，不可点击；next action 不指向未交付阶段。
- stage/order/status/retry/accessibility selectors 与 PR-006 一致；flag off 时没有 route/challenge 入口且旧详情测试保持兼容。
- 未创建 feature-local DTO、HTTP client、store、cache 或 version resolver。
