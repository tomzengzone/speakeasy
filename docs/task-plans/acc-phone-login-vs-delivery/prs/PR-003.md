# PR-003: WP-3 自动注册或登录判定（VS-ACC-010～012）

## Objective

交付验证码验证成功后的原子账号决策：已有手机号账号直接登录，未注册手机号自动
创建账号并登录，用户无需选择“注册”或“登录”。

## Included Scope

- `VS-ACC-010`：验证成功后自动判断手机号是否已注册。
- `VS-ACC-011`：已注册账号直接登录，未注册账号自动创建并登录。
- `VS-ACC-012`：用户无需手动选择注册或登录分支。
- 覆盖账号创建失败、登录态建立失败和重复提交等必要失败路径。

## Excluded Scope

手机号/验证码输入体验、短信发送机制、第三方登录和虚拟运营商号段风险决策。

## Allowed Paths

- `lib/pages/login_page.dart`
- `lib/services/auth_service.dart`
- `lib/services/app_session.dart`
- `lib/models/auth_models.dart`
- `lib/application/login/**`
- `backend/src/main/java/com/speakeasy/api/AuthController.java`
- `backend/src/main/java/com/speakeasy/identity/**`
- `backend/src/main/resources/db/migration/**`，仅在持久化变更确有必要时
- 对应的 `test/**`、`integration_test/**` 和 `backend/src/test/**` 认证测试文件
- API 边界确有变化时所需的既有契约及生成代码路径

## Acceptance Criteria

- 验证码验证成功后只执行一次账号存在性判定。
- 已注册手机号建立该账号的有效登录态，不创建重复账号。
- 未注册手机号只创建一个新账号并建立有效登录态。
- UI 不要求用户预先选择注册或登录。
- 账号创建失败或登录态建立失败时不留下伪成功状态，并给出可恢复结果。
- 重复提交不得创建重复账号或多个意外登录态。
