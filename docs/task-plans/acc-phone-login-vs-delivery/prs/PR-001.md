# PR-001: WP-1 手机号输入与验证码发送（VS-ACC-001-1～006）

## Objective

交付用户输入合法中国大陆手机号并主动发送短信验证码的完整阶段，包含发送资格、
重复点击保护和动态脱敏反馈。

## Included Scope

- `VS-ACC-001-1`：实时校验手机号位数和字符合法性。
- `VS-ACC-001-2`：默认 `+86`，按 11 位手机号规则校验。
- `VS-ACC-001-3`：手机号无效时禁用“发送验证码”按钮。
- `VS-ACC-001-4`：仅在用户主动点击后发送验证码。
- `VS-ACC-001-5`：发送后进入 60 秒倒计时并防止重复点击。
- `VS-ACC-001-6`：发送成功后展示基于当前手机号生成的动态脱敏提示。

## Excluded Scope

验证码输入、自动填充、验证码验证、账号注册/登录判定和风险策略。

## Allowed Paths

- `lib/pages/login_page.dart`
- `lib/services/auth_service.dart`
- `lib/models/auth_models.dart`
- `backend/src/main/java/com/speakeasy/api/AuthController.java`
- `backend/src/main/java/com/speakeasy/identity/**`
- 对应的 `test/**` 与 `backend/src/test/**` 认证测试文件
- API 边界确有变化时所需的既有契约及生成代码路径

## Acceptance Criteria

- 非数字、非 11 位或其他非法手机号立即显示错误，且发送按钮不可用。
- 默认展示/使用 `+86`，合法 11 位手机号使发送按钮可用。
- 未点击发送按钮时不产生短信发送请求。
- 一次点击只产生一次请求；发送成功后显示 60 秒倒计时并阻止重复发送。
- 成功提示根据实际输入动态生成，例如 `138****1234`，不得使用固定示例号码。
- 发送失败时不得错误展示发送成功状态；倒计时从点击还是发送成功开始须在实施前按正式行为来源确认。
