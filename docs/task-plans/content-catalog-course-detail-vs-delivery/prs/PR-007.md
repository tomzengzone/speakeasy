## Objective

独立交付 `VS-CONTENT-002-1` / `FR-CONTENT-002` 的版本固定 Course detail，并完成 001/002

- 从目录 Course summary card 携带同一 `course_id + course_version_id` 打开详情。

- missing/stale/hidden CourseVersion、失败重试、上下文保留和不替代其他版本/课程的状态。
- `TC-FR-CONTENT-002`、`TC-VS-CONTENT-002-1`，并回归 PR-006 FR/VS-TC 和整体 Flutter/Spring/API。

- 开始学习、课程路线/阶段、003–012、生产部署、远程 PR/merge、生产 migration 或正式 release 决策。

## Acceptance Criteria

- 目录课程卡片传递并解析同一 Course ID/version；详情不得自行读取 latest 或显示其他课程/过期版本。
- 必备字段全部可见且一致；duration > 0 并带单位，background null 不阻断也不显示破损图片错误。
- missing/stale/hidden/failed 状态提供契约规定的恢复或返回路径，并保留可安全展示的已知上下文。
- 四条 canonical Content FR/VS 测试、全量 Flutter、相关 Spring 和 API contract 验证通过。
- Evidence 记录 exact commit SHA、观测检查结果、灰度启用条件、rollback trigger/steps/result；未执行生产发布。
