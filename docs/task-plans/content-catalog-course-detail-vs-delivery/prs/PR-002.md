# PR-002: Course/CourseVersion/CourseContentBinding 领域与持久化契约

## Objective

在 PR-001 架构基线上定义 Course、CourseVersion、CourseContentBinding 的领域身份、关系、生命周期、
不变量、事实归属与 additive persistence contract，使后续 API 和 Spring 实现不再把 ScenarioLevel 当作 Course。

## Included Scope

- Course 稳定业务身份、所属主题/Scenario 引用与跨版本恒定事实。
- CourseVersion 的 version、英文标题、中文简介、唯一 CefrLevel、正值典型时长及单位、发布/可见事实、
  可选 background_asset_ref 和版本固定读取规则。
- CourseContentBinding 将每个 CourseVersion 绑定到一个 ScenarioVersion 和同一 Scenario 下、同一 CEFR 的
  ScenarioLevel；定义 cardinality、referential integrity 与错误处理。
- 新表/索引/unique/check/foreign-key、发布版本唯一性、不可变引用和 account deletion/retention 无用户数据影响的
  持久化契约；migration 只允许 additive forward change。
- 六条锁定 seed 的 Course/版本/绑定映射规则，不在领域契约中虚构更多内容。

## Excluded Scope

- SQL migration、JPA entity/repository/service/controller、API request/response、OpenAPI、Flutter 或测试实现。
- 003–012 的阶段进度、训练流细节、运行时 session、AI、媒体、学习证据或评分模型。
- 通用 CMS lifecycle、authoring workflow、Course 删除/编辑后台、ScenarioLevel 替换或 dual-write。

## Allowed Paths

- `docs/domain/domain_schema.md`
- `docs/domain/entity_relationship.md`
- `docs/domain/content_model.md`，新增 Course 专项 DOMAIN_MODEL
- `docs/task-plans/content-catalog-course-detail-vs-delivery/**`，仅计划状态、checkpoint 和证据

## Acceptance Criteria

- `Course`、`CourseVersion`、`CourseContentBinding` 均有 owner、稳定 ID、关键字段、cardinality、生命周期、
  不变量、持久化归属、migration implication 和 API handoff。
- 一条 CourseVersion 必须解析到恰好一个 Course、一个 ScenarioVersion 和一个 ScenarioLevel；三个引用的
  Scenario 与 CEFR 必须一致，无法一致解析时失败且不得替换其他课程、版本或等级。
- CourseVersion 的英文标题/中文简介非空、CEFR 仅六值之一、duration_value > 0 且 duration_unit 非空；
  background_asset_ref 可为 null，且 null 不影响发布或读取。
- `ScenarioLevel` 继续拥有单一 Scenario CEFR 内容轨道；本 PR 不删除、不重命名、不复制为 Course，也不改变
  mastery L0–L5 或 hint L1–L4 命名空间。
- 持久化方案支持六条 `2026.08-v1` seed，禁止虚构 A1/C1/C2 Course，并明确 additive migration 与安全回滚边界。
