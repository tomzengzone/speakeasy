# PR-003: 清理文档重复规则并完成全量治理验证

## Objective

清理 canonical Story Map 头部的重复方法规则，使其与新权威保持一致，并对全部治理变更执行最终验证和独立复核。

## Included Scope

- 仅修改 `docs/product/story_map.md` 的文档说明区，删除或压缩重复方法正文。
- 保留简洁的 Story Map/下游 Artifact 事实边界说明。
- 修正 Story/Slice delivery validator 测试的陈旧仓库计数和共享 catalog fixture 假设，使单元测试不因新增 approved Story/VS/FR/TC 而漂移。
- 对 PR-001～003 的组合候选运行全量验证并完成独立审查。

不重写、重排或批准任何现有 User Story/VS；不修改 `US-CONTENT-012`；不修改生产 validator 或其他测试；不创建下游 Artifact、实现报告、应用代码、Issue 或远程 PR。
